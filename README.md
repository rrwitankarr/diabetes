# Diabetes Prediction ML Dashboard

A futuristic Machine Learning dashboard built using HTML, CSS, JavaScript, and Python ML models for analyzing and comparing multiple algorithms on the Diabetes Dataset.

---

## Features

- Modern futuristic UI
- Dataset preview section
- Download full CSV dataset
- Confusion Matrix visualization
- Decision Tree visualization
- Accuracy comparison graph
- Interactive model sections
- Public deployment support using ngrok

---

## Algorithms Used

| Algorithm | Accuracy |
|-----------|-----------|
| Linear Regression | 94.16% |
| Random Forest Classifier | 95.44% |
| Decision Tree Classifier | 97.28% |
| XGBoost Classifier | 97.30% |

---

## Dataset Information

- Dataset: Diabetes Dataset
- Rows: 100,000
- Columns: 9
- Type: Binary Classification

### Features
- Gender
- Age
- Hypertension
- Heart Disease
- Smoking History
- BMI
- HbA1c Level
- Blood Glucose Level

### Target
- Diabetes (0 = No Diabetes, 1 = Diabetes)
